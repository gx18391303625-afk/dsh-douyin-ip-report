# 页面流程与验证记录

## 固定流程

1. 打开专用浏览器，必要时扫码。默认类型「曝光肖像」正常；按本次任务切换「假冒专利」或「假冒商标」。
2. 将本次链接填入富文本框并点击「开始识别」。短链接填入页面时保留结尾 `/`，任务去重仍使用规范化链接。
3. 核对成功识别数量和实际内容 ID。记录平台过滤的重复、不可见等条目；页面的过滤说明不是这批数据的失败结果。
4. 填入对应固定话术；在证明材料区域上传并逐张检查完成。专利使用六张证明材料，商标使用一张。
5. 选择「自己举报」和「组织」，核对名称、联系电话及选中状态。缺少身份时创建，上传营业执照并「保存并使用」；此按钮不是最终提交。
6. 按本批授权处理材料转送声明并提交。记录点击及回执状态，表单清空本身不能证明成功。
7. 从历史回执核对批次和明细。分页全部读取，不能只看第一页；无法找到原记录时保留未知状态。

页面上的「假冒专利」「假冒商标」各自有对应的描述占位文案；执行器切换后会核对，不依赖录制坐标或 AX 编号。

## 平台过滤

- 页面的「自动去除重复、无法识别、24 小时内重复举报」是静态说明，不是失败回执。
- 识别结果可能少于输入；失败条目和原因应如实记录，不能算作已举报。
- 「24 小时内已举报过」只证明本次重复提交失败；原举报状态必须回查历史。
- 「举报内容已不可见」表示平台无法定位当前内容（可能已删除或仅自己可见），不等同于审核通过。

## 已验证范围

开发期已在真实抖音举报页面覆盖：专利/商标类型切换、链接识别、话术填写、6 张/1 张证明材料上传、组织身份核验、缺失组织创建与营业执照上传、最终提交及历史回执读取。具体数量不在本仓库公开；这些是开发环境当日的状态，不能作为其他账号或以后的结果。

提交成功、平台受理和审核通过是不同状态。批次「已完成」不代表每个视频都成功，仍需看明细。

## 停止条件

页面变化导致定位、上传、身份核验或回执解析失败时停止，并在输出中指出具体控件或解析位置；不猜测选择器后继续提交。用户要求不抢前台，不自动降级为系统鼠标键盘操作。
