# 资料目录

首次使用时请把下面这些文件放进本目录（默认文件名）：

- `侵权问题话术.xlsx`：把「专利侵权话术」「商标侵权话术」下方的占位描述换成你的真实话术。
- `专利投诉材料1.jpg` 至 `专利投诉材料6.jpg`：专利证明材料，PNG/JPG/JPEG，单张不超过 5MB。
- `商标投诉材料.png`：商标证明材料。
- `专利侵权的组织身份.png`、`商标侵权的组织身份.png`：身份截图，仅用于核对，不能代替营业执照。
- `patent-license.jpg`、`trademark-license.jpg`：对应组织的营业执照。

如果实际文件名不同，编辑本目录的 `materials.json`（可参考 `materials.json.example`），字段说明见技能里的 `references/materials.md`。

不要把本目录、`materials.json`、身份或执照提交到公开仓库。
